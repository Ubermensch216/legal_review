## 실제 결과에서 확인한 결함

1. 02·05의 생략 쟁점에는 공백이 0개였고 `reasoning.gate`가 `OK`였다. 03에도 생략 쟁점 1개가 있었다. 생략을 `MISSING_AUTHORITY` 공백으로 남기고 `HUMAN_REVIEW_REQUIRED` 게이트를 세우도록 수정했다.
2. 01의 외부 질의 공백 6개는 근로자 동의, 근로시간, 수당 산정 자료 등 사실 부족을 설명하는 문장이었다. 입증 부족을 설명하는 질문은 사용자 확인으로 분류하도록 수정했다. 저장된 전체 검토 결과를 새 분류 규칙으로 다시 계산하면 01은 외부 질의 6→0개, 사실 확인 6개다. 같은 방식으로 03은 외부 질의 9→2개, 04는 10→1개다. 이는 **저장 결과의 오프라인 재계산**이며 모델을 다시 실행한 수치는 아니다.
3. 04의 공식 인용 11개 중 2개(`개인정보 보호법 시행령 제30조 제1항 제1호`, `제14조의2 제1항 제4호`)는 인용 검증기가 확인하지 못했다. 검증 오류인지 자료 형식 차이인지 확인 전에는 인용을 확정할 수 없다. 기대 조문 8개 중 2개만 인용했다.
4. 01의 모든 결론은 `CONDITIONAL`이었다. 결정 요건에 `UNKNOWN`·`DISPUTED`가 있고 입증이 `INSUFFICIENT`·`NO_EVIDENCE`인 경우가 많으므로 코드의 유보 규칙과는 일치한다. 다만 I5(경업금지·위약벌)의 열린 질문이 포괄임금제에 관한 문장으로 나와 쟁점 일치 품질이 부족하다. 유보가 법리적으로 모두 타당하다는 판정은 아니다.
5. 01에서 S3 요건 분해가 `A5`, `A2`를 골격으로 대체했다. 모델 응답 ID 매칭 완화는 벤치마크 프로세스 시작 후 반영되어 이 결과에 적용되지 않았다. 04에서도 11개 조문 중 9개가 골격이었다. 다음 측정에서는 `diagnostics.elements`의 골격 비율을 품질 지표로 기록해야 한다.
