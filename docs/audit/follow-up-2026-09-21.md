# 잔여 과제 후속 작업: API 계약 확대 및 수집 진단

> **과거 표본 검증:** 아래 공식 API 응답·건수는 2026-09-21 표본 실행 기록이며 현재 API 상태나 모든 법령의 계약을 보증하지 않는다. 현재 구현과 단계형 전환 판단은 [현황 문서](../current-status.md)를 따른다.

2026-09-21 · 기존 구현 기록 이후 수행한 작업. 전체 잔여 과제의 완료 보고서는 아니다.

다음 작업 기록: [입력 예산과 장문 발췌 개선](context-budget-2026-09-21.md).

## 완료한 작업

1. 실제 API 통합 테스트를 현행 법령·판례에서 연혁·과거 시행일·해석례로 확대했다.
2. 실제 해석례 목록 응답의 `Expc` 루트, `회신기관명`, `회신일자`, `법령해석례상세링크`를 지원했다. 기존 `ExpcSearch` 계약도 유지한다. 실패 `resultCode`를 빈 성공 목록으로 취급하지 않는다.
3. 본문 미확보를 네트워크, 시간 초과, HTTP 상태, XML 형식, 예상 외 루트, 필수 필드 누락, 일련번호 및 사건번호 불일치로 구분한다. 일반 네트워크 예외의 원문 URL은 결과에 노출하지 않는다.
4. 워크벤치의 `meta.retrievalAvailability`에 판례·해석례별 목록 건수, 본문 확보·미확보 건수, 상태와 실패 유형별 건수를 포함한다. 재정렬 전 전체 조회 후보를 집계하며 미확보 건수는 기존 제한 경고에도 반영한다.

## 실제 측정

설정된 LAW_OC로 공식 API를 호출했다. 인증값은 기록하지 않았고 테스트는 임시 캐시를 사용했다.

| 확인 대상 | 결과 |
| --- | --- |
| 개인정보 보호법 목록·본문 | 성공 |
| 같은 법령의 버전 목록 | 23건 |
| 2020-01-01 시점 제15조 | 2017-10-19 시행 버전 선택 및 본문 조회 성공 |
| 개인정보 해석례 상위 3건 | 목록 3건, 상세 본문 3건 확보 |
| 손해배상 판례 상위 3건 | 목록 3건, 상세 본문 1건 확보, 2건은 예상 외 응답 루트 |

판례의 예상 외 응답 루트만으로 권한 문제라고 단정하지 않는다. 제공 범위 또는 권한의 원인 규명은 추가 확인이 필요하다. 상위 3건의 가용성은 전체 서비스 성공률이나 법률 검토 정확도의 추정치가 아니다.

## 검증

- `npm test`: 49개 통과, 실패 0, skip 0.
- `npm run test:integration`: 4개 통과, 실패 0, skip 0.
- 픽스처 테스트에서 실패 유형, 비밀이 포함될 수 있는 일반 연결 오류 메시지 비노출, 통계의 JSON 보존, 실제 Expc 응답 형식과 오류 상태를 검증했다.
- 워크벤치 테스트에서 전체 후보의 미확보 건수가 재정렬로 사라지지 않고 제한 경고에 포함됨을 확인했다. HTTP 테스트에서 미설정 상태의 통계도 응답에 보존됨을 확인했다.

## 남은 작업

- 더 다양한 법령·시점·API 실패 상태에 대한 계약 검증. 이번 성공은 위 표본 범위에 한정된다.
- 전문가가 승인한 정답과 실제 LLM을 이용한 법리 품질 평가. API 본문 확보와 별도 지표가 필요하다.
- 모델별 토큰 예산 및 장문 회수율 평가.
- 완전한 위임 관계 탐색과 부칙 경과조치 적용.
- 브라우저 및 Word/한글에서 시각적 호환성 확인.
- 외부 공개 운영을 위한 사용자 인증·권한 관리.
