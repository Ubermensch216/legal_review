# 계약서 검토 v2 구현 점검

## 반영 범위

- S2의 검색 후보와 적용 근거를 분리했다. 후보의 조문·법률·쟁점·사실·의미 유사도 특징을 남기고 관련성이 낮은 판례·해석례는 S4 입력에서 제외한다.
- S6 함의 결과를 명제별 `rulePropositions`로 연결했다. 공식성·기준일 효력·원문·명제 대응이 확인된 ID만 `appliedAuthorities`와 보고서 법적 근거에 표시한다. 민법 제673·689·103조, 민사소송법 제29조, 저작권법 제45·14조에 관한 명제는 다른 조문으로 대체하지 못하도록 검사한다.
- 요건, 계약 사실, 포섭 상태를 별도 필드로 저장한다. 출처 확인 문구는 요건에서 제외하고 동일한 요건 문구는 합친다.
- S5에는 쟁점별 축약 객체만 전달한다. 입력 한도의 80%를 넘으면 재압축하고 90%를 넘으면 두 묶음으로 나눠 요약한 뒤 최종 종합한다.
- 전속관할과 법정 분쟁절차 포기를 분리하고 민사소송법 제29조 검색을 추가했다. 누락조항은 부재·불완전·모호·충분·비적용으로 구분한다.
- 문언상 위험과 법적 효력 평가를 분리한 위험 축을 저장한다. 공식 근거가 부족한 높은 문언 위험은 확정 등급 대신 `HIGH_CANDIDATE`로 표시한다.
- 계약 보고서 본문을 요약·핵심 위험·쟁점·조항별 검토·수정안·추가 확인사항으로 조립하고, 근거 및 검증 기록은 부록으로 보낸다. PDF 본문에서 UI 토큰과 원시 Markdown을 제거한다.
- 외부 지식의 영향 쟁점·요건과 공식 근거 연결 여부를 기록한다.

## 검증 및 한계

- `npm test`: 256건 통과, 0건 실패. 실제 계약 DOCX의 10개 세부 쟁점, 부재와 불완전의 구분, 문서 근거 연결, 종합 요약 생성, PDF 재추출, 저작재산권 양도 명제의 조문 연결, 외부 답변의 누락 조문 공식 확인을 포함한다.
- 법령 번호와 조문 표제는 국가법령정보센터의 [민법 제103조](https://law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0103&lsiSeq=284415&urlMode=lsScJoRltInfoR), [제673조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0673&lsiSeq=284415&urlMode=lsScJoRltInfoR), [제689조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0689&lsiSeq=284415&urlMode=lsScJoRltInfoR), [민사소송법 제29조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1028533517)와 대조했다. 실제 사건의 법적 효력은 계약 성질, 발주기관 유형, 판례 사실유형의 추가 확인에 달려 있다.
- 첫 실제 실행(`gemma4:e4b`, 법령 API 설정됨)은 10개 쟁점, 종합 생성 성공, 문서 연결률 100%, 적용 근거 공식성 100%, 제안된 명제·근거 쌍의 검증 통과율 약 91.8%, 문서 근거 검증 100%였다. 상태는 `PARTIAL`이었다. 처음 생성한 PDF는 본문 12쪽·부록 포함 17쪽이어서 추가 확인사항과 반복 사실을 압축했다.
- 두 번째 실제 실행은 10개 쟁점을 유지했고 문서 연결률·법령 후보 회수율·최종 적용 근거의 공식성·누락조항 분류·수정안 생성·종합 성공률이 각각 100%였다. 제안된 명제·근거 쌍의 검증 통과율은 74.1%, S6 주장 검증 지지율은 90.9%였다. 상태는 `PARTIAL`, 게이트는 `HUMAN_REVIEW_REQUIRED`이다. PDF는 본문 9쪽, 부록 포함 15쪽이며 재추출 검사에서 내부 UI 토큰과 원시 Markdown이 검출되지 않았다.
- 두 번째 실행에서 저작재산권 양도 명제를 저작권법 제14조에 연결하거나 지체상금 명제를 무관한 해석례에 연결한 후보가 드러났다. 이후 S2 해석례 관련성 조건, S4 원 출처 조문 유지, 저작권법 제45·14조 명제 대응 검사를 강화하고 회귀 테스트를 추가했다. 이 마지막 수정은 실제 모델·법령 API 전체 실행으로 다시 측정하지 않았으므로 위 수치는 수정 전 결과이다.
- `authorityOfficialRate`는 표시 근거의 공식성·시점 유효성 비율이다. `authorityPrecision`은 표시 근거가 해당 쟁점의 명제에 대해 S6 지지 판정을 받은 비율이며 두 번째 실행에서 100%였다. `ruleAuthorityAccuracy`는 모델이 제안한 명제·근거 쌍 중 검증을 통과한 비율이다. 검증에서 탈락한 쌍을 법적 근거로 승격하지 않는 것이 현재 게이트의 목적이다. 이 자동 지표는 법률 전문가의 독립 평가를 대신하지 않는다.
